    檔案限制與注意事項

    靜態 JPEG / PNG；單張最多 1,600 萬像素，任一邊最多 8,192 px。不支援動態圖片、既有 PDF、OCR、加密、簽章或列印。

    透明區會轉成白色，照片重新編碼為 JPEG，可能有些微畫質改變。小圖可能放大，工具不會提升原始清晰度。瀏覽器的記憶體或編碼限制也可能使處理失敗。

    加入要合併的 JPEG 或 PNG；順序可在下一步調整。

    常見問題

    圖片會被裁切或放大嗎？

    不裁切；會按比例縮放至頁面邊界內並置中，剩餘位置留白。小圖可能放大，但不會增加照片細節。

    照片方向會照相機方向嗎？

    先使用支援的 EXIF 方向，再套用你選的額外旋轉。瀏覽器解碼尺寸與方向不符時會停止。請用照片預覽檢查鏡像與閱讀方向。

    PDF 會留下檔名或 GPS 資料嗎？

    不會加入來源檔名或照片 metadata；PDF 只含重新編碼的頁面影像。影像畫面中的姓名、地址等內容仍會保留，請自行檢查。
